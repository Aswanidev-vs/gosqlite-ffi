SQLite from Go.
Without CGO.

A small, transparent experiment in calling SQLite's native C API from Go using purego. No C compiler in your build pipeline; still uses a trusted SQLite shared library at runtime.

THE APPROACH

Small surface. Clear trade-offs.

GoFFI SQLite aims to make the native boundary explicit instead of hiding it behind a large abstraction too early.

↔

CGO-free calls

Resolve native symbols at runtime through purego and avoid compiling Go code through CGO.

◈

Upstream SQLite

Reuse SQLite itself rather than reimplementing SQL, storage, or transaction semantics.

⌘

Explicit lifecycle

Keep library loading, errors, ownership, and resource lifetime visible and reviewable.

FIRST CALL

Read the runtime version

Install a compatible native SQLite library, then use the diagnostic API.

main.go
package main

import (
    "fmt"
    "log"

    "github.com/Aswanidev-vs/gosqlite-ffi/sqliteffi"
)

func main() {
    lib, err := sqliteffi.LoadDefault()
    if err != nil {
        log.Fatal(err)
    }
    defer lib.Close()

    version, err := lib.Version()
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println("SQLite", version)
}

Deployment note: CGO-free does not mean self-contained. For deterministic deployments, use sqliteffi.Load with a trusted absolute library path.

PRACTICAL EXAMPLES

Use the API that exists today

GoFFI SQLite now supports database connections, parameterized statements, transactions, and the standard database/sql interfaces.

Example 1 · Print version and numeric version
package main

import (
    "fmt"
    "log"

    "github.com/Aswanidev-vs/gosqlite-ffi/sqliteffi"
)

func main() {
    lib, err := sqliteffi.LoadDefault()
    if err != nil {
        log.Fatal(err)
    }
    defer lib.Close()

    version, err := lib.Version()
    if err != nil {
        log.Fatal(err)
    }

    number, err := lib.VersionNumber()
    if err != nil {
        log.Fatal(err)
    }

    fmt.Printf("SQLite version: %s (number %d)\\n", version, number)
}
Example 2 · Load a specific library
package main

import (
    "fmt"
    "log"

    "github.com/Aswanidev-vs/gosqlite-ffi/sqliteffi"
)

func main() {
    // Use an absolute path to a trusted SQLite shared library.
    lib, err := sqliteffi.Load("/usr/lib/x86_64-linux-gnu/libsqlite3.so.0")
    if err != nil {
        log.Fatal(err)
    }
    defer lib.Close()

    version, err := lib.Version()
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(version)
}

Platform note: The explicit path above is an example for some Linux distributions; use the actual absolute path on your system. Windows and macOS use different library names and locations.

Example 3 · Install and run
go get github.com/Aswanidev-vs/gosqlite-ffi
go run .

Important: The native SQLite shared library must be installed and discoverable when using LoadDefault. This package is experimental; review the platform notes and run the test suite on your target OS before production use.
