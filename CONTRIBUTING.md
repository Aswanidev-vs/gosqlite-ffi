# Contributing

Thanks for helping make GoFFI SQLite easier to use and verify.

- Keep changes focused and idiomatic Go.
- Add tests with every new public API or bug fix.
- Run `gofmt`, `go test ./...`, and `go vet ./...`.
- Explain native dependencies and test environment in pull requests.
- Do not add generated native libraries or secrets to the repository.
- For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public exploit report.

This project is experimental. Pull requests must not describe features as production-ready without appropriate integration tests, platform coverage, and review.
